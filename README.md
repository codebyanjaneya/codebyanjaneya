FastAPI, PostgreSQL, and LLMs are my usual toolkit, and I gravitate toward problems that involve concurrency, geospatial data, or getting AI to do something actually useful.

These days I'm interning as a full-stack developer at Gleska and doing R&D at RootStock Technologies.

## What I'm building right now

**H.E.R.C.S** — a fully offline, JARVIS-style desktop voice assistant. Clap twice or say the wake word and it listens, thinks, and answers in a cloned voice, while genuinely running the machine through LLM tool-calling (launching apps, reading system stats, taking screenshots). Speech-to-text and the voice cloning both run 100% on-device.

## A few things I've made

- **AgentForge** — a simulated company run by 7 autonomous LLM agents that delegate work and message each other over a Redis event bus, with a live dashboard to watch the decisions happen. [Live](https://agentforge-omega-topaz.vercel.app/)
- **AutoApply Bot** — a multi-tenant Telegram SaaS that automates the whole job hunt: resume parsing, matching with Groq Llama, and recruiter outreach, with per-tenant Razorpay billing. [Live](https://autoapply-landing-sand.vercel.app/)
- **AI-PhishGuard** — a phishing detector that pairs a scikit-learn model with an LLM for context, then cross-checks each verdict against VirusTotal and WHOIS. Handles single URLs and bulk CSVs. [Live](https://ai-phishguard.web.app/)
- **DermaCam** — a Flutter app that runs a 7-model ensemble to classify skin conditions from a phone camera, with a Hinglish voice assistant that explains the results in plain language.
- **LoadPulse** — a concurrency and observability platform I built to stress-test async systems; benchmarked past 1000 concurrent requests with a live latency/throughput dashboard. [Live](https://loadpulse-dashboard.vercel.app/)
- **Nudge** — a small app that hands you exactly one concrete next step toward a goal instead of a giant to-do list. [Repo](https://github.com/codebyanjaneya/Nudge)
